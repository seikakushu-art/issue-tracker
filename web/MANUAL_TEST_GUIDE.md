# 手動テスト手順書

Playwrightの自動テストがうまくいかない場合の、全機能を手動でテストするための手順書です。

## テスト前の準備

1. 開発サーバーを起動: `ng serve` または `npm start`
2. ブラウザで `http://localhost:4200` を開く
3. テスト用のアカウントを2つ以上用意（プロジェクト招待機能のテストのため）
